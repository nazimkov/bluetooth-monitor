# Privacy Policy

**Last updated: 17 September 2026**

Bluetooth Monitor is a Windows application that shows battery levels for paired Bluetooth audio devices. This policy explains what information the application uses and where it is stored.

## Information processed on your device

Bluetooth Monitor reads the following information from Windows when you scan or monitor a device:

- The name and connection state of paired Bluetooth audio devices.
- Battery levels reported by those devices.
- The device selected for monitoring and your application settings.

Bluetooth device information is processed in the application on your Windows device. The application does not send Bluetooth device names, identifiers, connection states, or battery levels to the developer.

Application settings are stored locally in `%LOCALAPPDATA%\BluetoothMonitor\settings.json`. Application logs are stored locally in `%LOCALAPPDATA%\BluetoothMonitor\Logs`. You can remove this information by closing the application and deleting the `BluetoothMonitor` folder in `%LOCALAPPDATA%`.

## Network access

Bluetooth polling does not use the network.

When you select **Check now** on the About page, Bluetooth Monitor requests release information from the GitHub API. GitHub may receive standard request information, such as your IP address, under its own privacy policy. The application does not include Bluetooth device information in this request.

When you open the privacy policy or a release link, Windows opens the link in your default web browser. Your browser and GitHub then process the request under their own privacy policies.

## Notifications

If you enable battery notifications, Windows displays notifications generated by the application. Bluetooth Monitor does not send notification data to an external service.

## Third-party services

The project source code and privacy policy are hosted on GitHub. GitHub is operated by GitHub, Inc. GitHub's services are subject to GitHub's own terms and privacy policy.

## Changes to this policy

This policy may change when the application changes. The current version is available in the project repository at the link in the application.

## Contact

For questions about this policy, open an issue in the Bluetooth Monitor repository on GitHub.
